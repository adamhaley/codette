System Notes

Codette patterns are built to stay reusable.

  • Content-first section composition
  • Theme tokens separated from layout
  • Plain HTML and CSS with tiny JS only when needed

Approach

Keep the generator boring. Put the sophistication in the patterns.

The generator should mostly validate, render, and write files. That keeps the architecture stable while the pattern library grows through actual usage.

  • Each section pattern owns its markup and responsive behavior.
  • Themes define tokens, not content structure.
  • Site specs stay shallow enough for agents to edit confidently.

Small systems age better when they resist abstraction until reuse is obvious.
